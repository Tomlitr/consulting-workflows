# 03 – Wording-Lexikon: Rot → Grün

Arbeitsliste für den Textdurchgang. Die rechte Spalte ist kein Euphemismus, sondern die
**präzisere** Beschreibung von Beratungsarbeit — das ist die Voraussetzung dafür, dass die
Änderung trägt (siehe Vorbehalt in der README).

## 1. Rollen und Selbstbezeichnung

| Rot | Warum riskant | Grün |
|---|---|---|
| Trainer, Trainerin | Begriff, unter den die DRV subsumiert | Berater, Beraterin · Unternehmensberater |
| Dozent, Lehrbeauftragter | namentlich erfasste Lehrtätigkeit | (streichen) · Praxiserfahrung in den Vordergrund |
| Coach *ohne Erläuterung* | wird regelmäßig als Lehre eingeordnet | Coach **als Prozessbegleiter**, mit den vier Merkmalen aus `01`, Abschnitt 4 |
| Speaker, Referent | Vortrag = Wissensvermittlung | Impulsgeber im Mandat · (oder streichen) |
| Lehrer, Ausbilder, Mentor | direkter Tatbestandsbezug | Sparringspartner · Begleiter |
| Akademie, Institut, Schule | Institution der Lehre | Beratung · Practice · Partnernetzwerk |

## 2. Formate und Produkte

| Rot | Warum riskant | Grün |
|---|---|---|
| Kurs, Kurse | Kernindiz | Mandat · Beratungsprojekt · Leistung |
| Lektion, Lesson, Modul, Kapitel | Unterrichtseinheit | Arbeitssitzung · Projektphase · Working Session |
| Seminar, Schulung, Lehrgang | Unterricht | Klausur · Strategiesitzung · Arbeitstreffen |
| Training, Weiterbildung | Wissens-/Fertigkeitsvermittlung | Umsetzungsbegleitung · Befähigung im Projekt |
| Workshop | **ambivalent** — als offenes Format riskant | Arbeitssitzung · Klausurtagung; nur unbedenklich, wenn erkennbar am *eigenen* Fall des Kunden gearbeitet wird |
| Praxisworkshop, Übung | „praktischer Unterricht" ist ausdrücklich erfasst | Erprobung im laufenden Betrieb · Pilotierung |
| Programm, Curriculum, Lehrplan | feststehender Inhalt | Vorgehen · Projektarchitektur · Roadmap |
| Zertifikat, Teilnahmebescheinigung, Prüfung | Lehrbetrieb | (ersatzlos streichen) |
| Online-Kurs, Selbstlernpfad, E-Learning | reine Wissensvermittlung | strukturell zu lösen, nicht sprachlich (`02`, F-02) |

## 3. Adressaten

| Rot | Warum riskant | Grün |
|---|---|---|
| Teilnehmer, Teilnehmende | Rolle im Unterricht | Klient · Auftraggeber · Kunde · Führungskreis · Projektteam · Leitungsteam |
| Schüler, Lernende, Kursgruppe | eindeutig | Beteiligte · Verantwortliche · Entscheider |
| Zielgruppe „alle Führungskräfte" | unbestimmte Vielzahl | benannte Rollen in einer benannten Organisation |

## 4. Verben und Wirkungsversprechen

| Rot | Warum riskant | Grün |
|---|---|---|
| vermitteln | Wortlaut des Tatbestands | erarbeiten · entwickeln · einführen · verankern |
| lehren, beibringen, schulen, ausbilden | direkt | begleiten · beraten · konzipieren · moderieren einer Entscheidung |
| „Sie lernen …" | Lernziel | „Sie entscheiden …" · „Sie verfügen danach über …" (Arbeitsergebnis) |
| Wissen aufbauen, Know-how-Transfer | genau der Gegenstand der Lehre | Handlungsfähigkeit herstellen · Steuerungsfähigkeit verbessern |
| Kompetenzen/Fähigkeiten/Fertigkeiten aufbauen | Wortlaut der Definition | Rollen klären · Verantwortung verankern · Zusammenarbeit neu ordnen |
| Methodenkompetenz, Toolbox, Werkzeugkasten | Kursinhalt | Steuerungsinstrumente des Unternehmens |
| Best Practices weitergeben | generelles Wissen | Erfahrung auf **Ihre** Ausgangslage anwenden |
| Lernprozess, Lernbegleitung, Lernreise | schwerstes Risikowort | Veränderungsprozess · Entscheidungsprozess · Transformationsvorhaben |

## 5. Englische Seiten (`/en/`)

Gleiche Logik, eigene Fallen — „training" und „lessons" sind im Englischen noch
eindeutiger.

| Rot | Grün |
|---|---|
| training, trainer | advisory, consulting, consultant |
| course, courses, lesson | engagement, mandate, working session |
| curriculum, syllabus, module | approach, project architecture, phase |
| participants, attendees | client, client team, leadership team |
| teach, convey, impart knowledge | analyse, design, facilitate, implement |
| learning process, learning journey | change process, decision process |
| skills, tools & techniques | governance, operating model, steering instruments |
| workshop *(offen ausgeschrieben)* | working session, off-site, strategy session |
| book a course / seats | request a proposal · initial conversation |

## 6. Grenzfälle, bewusst zu entscheiden

- **Moderation / Facilitation.** Die DRV zählt Moderatoren in ihrer Praxis mitunter zu den
  Lehrern. Unbedenklich wird es, wenn erkennbar ist, dass ein **Entscheidungs-** oder
  **Klärungsprozess** moderiert wird und nicht ein Lernsetting: „Moderation der
  Zielbildklausur des Vorstands" ist gut, „Moderationstraining" ist es nicht.
- **Supervision.** Ambivalent. Als Reflexionsformat gut beschreibbar, als Ausbildungsteil
  riskant. Wenn möglich durch „Fallreflexion" oder „Sparring" ersetzen.
- **Vortrag / Keynote.** Reine Wissensvermittlung an eine unbestimmte Zuhörerschaft. Wenn
  Vorträge stattfinden, sollten sie als **Akquisemittel** und nicht als Leistungsangebot
  auftreten — und im Umsatzanteil klein bleiben.
- **Blog, Artikel, Publikationen.** Unproblematisch: Publizistik ist keine Lehre im Sinne
  des § 2. Fachartikel sind sogar nützlich — sie belegen Beratungsexpertise. Nur die
  Rubrik nicht „Wissen", „Lernen" oder „Academy" nennen.
